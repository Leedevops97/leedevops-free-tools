# Server Lens

Version **1.0.0** · **Free / MIT** · Linux only

Run `sh server-lens` from this folder. Use `--help` for all options.

For an optional per-user install, copy the reviewed file to
`~/.local/bin/server-lens`, make it executable with `chmod +x`, and ensure
`~/.local/bin` is in PATH. No installer or service is required. Remove that
single file to uninstall.

The repository [README](../../README.md) explains metrics, privacy,
compatibility and limits. [中文](../../docs/README.zh-CN.md).

## 1.0.0

First release: resource dashboard, recent-login history, time synchronization
evidence, optional refresh, JSON, terminal-width handling and report redaction.
All operations are local and read-only. No account or payment is required.
